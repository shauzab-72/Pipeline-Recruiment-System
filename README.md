# Pipeline-Recruiment-System
A dynamic recruitment pipeline for LinkedIn implemented as a Singly linked list where each node represents a hiring stage and contains a dynamic array of candidate objects. Supports adding custom stages anywhere in the pipeline process.
# Key features:
1) add a new stage anywhere
2) delete an existing stage
3) thorough traversal of every array index through every stage
4) jagged candidate storage
5) many linear time complexity functions
